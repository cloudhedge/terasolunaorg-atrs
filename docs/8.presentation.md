_Thought Process behind it_

One of the ways we though we could showcase the CHAI Universe capabilties is to make a legacy app aka ARTS as AI native. We make the app AI native by adding a layer of MCP around the app. This would enable AI systems to talk or interact i.e. take action with legacy system.

To convert a souce code into a MCP we divide it into 3 steps
Step 1: Analyze the souece code and create an architectire document
Step 2: Read this architecture doc, analyze the end points and create an mcp server
Step 3: Configure the MCP server with CLaude desktiop app and let Claude interact with the legacy app ATRS and showcase a demo of claude booking the ticket for me
