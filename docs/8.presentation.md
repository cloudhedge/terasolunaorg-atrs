What was the requirement/What did client want?
---
Client had given us their OSS repo TERASOLUNA ATRS.

TERASOLUNA is a template for Java Spring Projects which is used across all the NTT Data projects. 
ATRS is Airline Ticket Reservation System which is a sample application written with TERASOLUNA template using Java Spring and JSP to demonstrate how a project should be scaffolded or wired or architected.

ATRS is a system which allows users mainly to search flights or to reserve flights. ATRS also has login, register, booking details, passenger details features as well.

Client wanted to see the capabilities of CHAI Universe.

GitHub link - https://github.com/terasolunaorg/atrs



What Capabilities do we want to show for CHAI?
---

_Thought Process behind it_

One of the ways we thought we could showcase the CHAI Universe capabilities is to make a legacy app aka ATRS as AI native. We make the app AI native by adding a layer of MCP around the app. This would enable AI systems to talk or interact i.e. take action with legacy system.

To convert a source code into an MCP we divide it into 3 steps:
Step 1: Analyze the source code and create an architecture document
Step 2: Read this architecture doc, analyze the endpoints and create an MCP server
Step 3: Configure the MCP server with Claude Desktop app and let Claude interact with the legacy app ATRS and showcase a demo of Claude booking the ticket for me

__​Source Code → Architecture Doc__ : CHAI Universe analyzes a codebase and generates architecture documentation.

**Video Script :**

__​​Source Code → MCP Server (End-to-End)__ : CHAI Universe analyses a Java Spring codebase and generates an MCP server, making the legacy application AI-native

**Video Script :**
- CHAI Universe TUI is shown
- User inputs `/source-code-to-mcp` custom command
- CHAI Universe scans the architecture doc and source code repo using a subagent
- Creates a new folder called `atrs-mcp-server` and scaffolds an MCP server in Node.js
- Adds the necessary type definitions to expose metadata to the AI Agent that will use this MCP
- Adds the source code for the MCP server
- Tests the MCP server

**​MCP + Claude Desktop Integration**​ : Configuring the generated MCP server with Claude Desktop to search and book tickets, enabling AI to interact with the legacy app
