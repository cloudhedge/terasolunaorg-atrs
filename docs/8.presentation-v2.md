# CHAI Universe Capabilities Presentation

## Acronyms

| Acronym | Definition |
|---------|------------|
| CHAI | CloudHedge Agentic Intelligence System |
| CHAI Universe | CLI-based Agentic Modernization Tool |
| MCP | Model Context Protocol - Standard for connecting AI to data sources/tools |
| ATRS | Airline Ticket Reservation System |
| TERASOLUNA | NTT Data's Java Spring project template |

---

## Context

### Client Request
NTT Data provided their OSS repo **TERASOLUNA ATRS** to demonstrate CHAI Universe capabilities.

### What is ATRS?
- Sample airline reservation app built with TERASOLUNA template
- Tech: Java Spring + JSP
- Features: Flight search, booking, login, registration, passenger management
- Repo: https://github.com/terasolunaorg/atrs

---

## Objective

**Goal:** Make a legacy app AI-native by wrapping it with MCP

### Thought Process

To showcase CHAI Universe capabilities, we transform a legacy app (ATRS) into an AI-native system by adding an MCP layer. This enables AI systems to interact with and take actions on the legacy system.

```
┌─────────────────────────────────────────────────────────────┐
│                      AI Agent (Claude)                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    MCP Server (Generated)                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   Legacy App (ATRS)                         │
└─────────────────────────────────────────────────────────────┘
```

---

## 3-Step Process

| Step | Action | Output |
|------|--------|--------|
| 1 | Analyze source code, create architecture doc | Architecture document |
| 2 | Read architecture doc, analyze endpoints, generate MCP | Node.js MCP server |
| 3 | Configure MCP with Claude Desktop, demo AI booking ticket | AI-native legacy app |

---

## Demo Videos

### Video 1: Source Code to Architecture Doc

**Command:** `/source-code-to-doc`

**Flow:**
1. Launch CHAI Universe TUI
2. Run `/source-code-to-doc` command
3. Agent scans codebase, generates architecture doc
4. Preview generated markdown at https://markdownviewer.pages.dev/
5. User requests fixes, agent updates doc
6. Final preview shows corrected documentation

**Demonstrates:** Automated codebase analysis and documentation generation

---

### Video 2: Source Code to MCP Server

**Command:** `/source-code-to-mcp`

**Flow:**
1. Launch CHAI Universe TUI
2. Run `/source-code-to-mcp` command
3. Subagent scans architecture doc + source code
4. Creates `atrs-mcp-server/` folder
5. Scaffolds Node.js MCP server with:
   - Type definitions for AI metadata
   - Server source code
6. Tests MCP server

**Demonstrates:** End-to-end MCP generation from legacy codebase

---

### Video 3: MCP + Claude Desktop Integration

**Flow:**
1. Open Claude Desktop (pre-configured with ATRS MCP)
2. Show MCP configuration
3. Query Claude about ATRS MCP capabilities
4. Request available flights
5. Book flight for Dec 26, 2025
6. Handle validation error (name must be in Katakana)
7. Claude converts username to Katakana script
8. Booking completes successfully

**Demonstrates:** AI interacting with legacy system via MCP

## Key Takeaways

- **CHAI Universe** automates legacy-to-AI-native transformation
- **3-step process**: Analyze → Generate MCP → Integrate
- **Result**: Claude can directly interact with legacy ATRS system
- **Value**: No manual API wrapper coding required
