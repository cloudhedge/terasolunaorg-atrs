1. Executive Summary

ATRS is a multi-module Java/Spring web application for airline ticket reservation. Built on the TERASOLUNA framework (v5.10.0), it demonstrates enterprise-grade patterns for a transactional booking system.

AttributeValue
Version1.11.0.RELEASE
Java17
FrameworkSpring MVC 6.x, Spring Security 6.x
ORMMyBatis
DatabasePostgreSQL
ViewJSP
MessagingActiveMQ Artemis (JMS)

9.3 Authentication Flow

sequenceDiagram
    actor User
    participant Filter as AtrsUsernamePasswordAuthFilter
    participant UDS as AtrsUserDetailsService
    participant Repo as MemberRepository
    participant Success as AuthenticationSuccessHandler
    participant Service as AuthLoginService

    User->>Filter: POST /auth/dologin
    Filter->>Filter: Validate credentials format
    Filter->>UDS: loadUserByUsername(membershipNumber)
    UDS->>Repo: findOneForLogin(membershipNumber)
    Repo-->>UDS: Member + MemberLogin
    UDS-->>Filter: AtrsUserDetails
    Filter->>Filter: Verify password
    Filter->>Success: onAuthenticationSuccess()
    Success->>Service: login(member)
    Service->>Repo: updateToLoginStatus()
    Success-->>User: Redirect to original URL
