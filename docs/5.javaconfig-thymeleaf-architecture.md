# JavaConfig-Thymeleaf Architecture

## Project Structure

```
JavaConfig-Thymeleaf/atrs/
├── atrs-env/        → Environment config, dependencies, JMS
├── atrs-domain/     → Business logic, entities, repositories
├── atrs-web/        → Controllers, REST APIs, Thymeleaf views
├── atrs-initdb/     → Database init scripts
└── pom.xml          → Parent Maven POM
```

## Layer Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    PRESENTATION LAYER                        │
│  ┌──────────────┐  ┌───────────────┐  ┌─────────────────┐   │

│  │ (app/)       │  │  (api/)       │  │  Views          │   │
│  └──────┬───────┘  └───────┬───────┘  └─────────────────┘   │
│         │                  │                                 │
│  ┌──────▼──────────────────▼───────┐                        │
│  │         Helpers & Mappers        │  (MapStruct DTOs)     │
│  └──────────────┬──────────────────┘                        │
├─────────────────┼───────────────────────────────────────────┤
│                 │        SERVICE LAYER                       │
│  ┌──────────────▼──────────────────┐                        │
│  │     Services (Interface+Impl)    │  @Transactional       │
│  │  a0/a1/a2, b0/b1/b2, c1/c2, d1  │                        │
│  └──────────────┬──────────────────┘                        │

│                 │        DOMAIN LAYER                        │
│  ┌──────────────▼────┐  ┌──────────────────────────────┐    │

└─────────────────────────────────────────────────────────────┘
```

## Security Flow

```
POST /auth/dologin
      │
      ▼
AtrsUsernamePasswordAuthenticationFilter
      │
      ▼
AtrsUserDetailsService.loadUserByUsername()
      │
      ▼
MemberRepository.findByMembershipNumber()
      │
      ▼
Success → AtrsAuthenticationSuccessHandler → Redirect
```

**Protected Routes:**
- `/member/update` → ROLE_MEMBER
- `/HistoryReport/**` → ROLE_MEMBER

## Key Config Classes

| Class | Purpose |
|-------|---------|
| `ApplicationContextConfig` | i18n, password encoding, JMS |
| `SpringMvcConfig` | Thymeleaf engine, interceptors |
| `SpringSecurityConfig` | Auth filters, form login |
| `AtrsInfraConfig` | MyBatis, JMS templates |

## Request Flow (Flight Booking)

```
1. GET /ticket/search?form     → Display search form
2. AJAX /api/v1/flights        → Search flights (JSON)
3. POST select flights         → Validate & redirect
4. GET /ticket/reserve?form    → Passenger info form
5. POST /ticket/reserve        → Token check + confirm
6. POST execute                → Book seats (FOR UPDATE lock)
7. Display complete/fail
```

## Two DispatcherServlets

| Servlet | Path | Config Class | Auth |
|---------|------|--------------|------|
| REST API | `/api/v1/*` | `SpringMvcRestConfig` | HTTP Basic (stateless) |
| Web MVC | `/` | `SpringMvcConfig` | Form login (session) |

## Filter Chain (execution order)

1. `MDCClearFilter` - MDC cleanup
2. `XTrackMDCPutFilter` - Request tracking
3. `CharacterEncodingFilter` - UTF-8
4. `ExceptionLoggingFilter` - Exception logging
5. `HttpMethodFilter` - PUT/DELETE support
6. `SpringSecurityFilterChain` - Auth
7. `AccessLogFilter` - Access logging
