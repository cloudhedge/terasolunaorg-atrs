     ATRS Java to Python Migration Plan

     Overview

     Migrate ATRS (Airline Ticket Reservation System) from Java/Spring to
     Python/FastAPI with exact feature parity.

     ┌─────────────────────┐     ┌─────────────────────┐
     │   Java (Current)    │     │   Python (Target)   │
     ├─────────────────────┤     ├─────────────────────┤
     │ Spring MVC + REST   │ ──► │ FastAPI             │
     │ MyBatis (raw SQL)   │ ──► │ databases + asyncpg │
     │ Spring Security     │ ──► │ FastAPI Security    │
     │ JMS (Artemis)       │ ──► │ arq + Redis         │
     │ JSP Views           │ ──► │ API-only (no views) │
     └─────────────────────┘     └─────────────────────┘

     Scope: 217 Java files → ~80 Python files
