> how can I package this so this is easily installed? 

⏺ Best approach: Publish to npm so users can run via npx.

  Option 1: npm Package (Recommended)

  Update package.json:

  {
    "name": "@sandipwane/atrs-mcp-server",
    "version": "1.0.0",
    "description": "MCP server for ATRS flight reservation APIs",
    "type": "module",
    "bin": {
      "atrs-mcp-server": "dist/index.js"
    },
    "files": ["dist"],
    "main": "dist/index.js",
    "scripts": {
      "build": "tsc",
      "prepublishOnly": "npm run build"
    },
    ...
  }

  Publish:
  cd atrs-mcp-server
  npm login
  npm publish --access public

  Users then configure:
  {
    "mcpServers": {
      "atrs": {
        "command": "npx",
        "args": ["-y", "@sandipwane/atrs-mcp-server"],
        "env": {
          "ATRS_API_BASE_URL": "http://localhost:8080/atrs/api"
        }
      }
    }
  }

  ---
  Option 2: GitHub-based Install

  No npm publish needed. Users install via:

  {
    "mcpServers": {
      "atrs": {
        "command": "npx",
        "args": ["-y", "github:sandipwane/atrs-mcp-server"],
        "env": {
          "ATRS_API_BASE_URL": "http://localhost:8080/atrs/api"
        }
      }
    }
  }

  Requires: "bin" field in package.json + built dist/ committed or build on install.

> this is in a private repo of cloudhedge will it work? 

⏺ For a private repo, the GitHub install won't work out of the box (auth issues). Here are your options:

  Option 1: GitHub Packages (Best for Private)

  Publish to GitHub's npm registry (free for private repos):

  1. Add .npmrc to the repo:
  @cloudhedge:registry=https://npm.pkg.github.com

  2. Update package.json:
  {
    "name": "@cloudhedge/atrs-mcp-server",
    "repository": {
      "type": "git",
      "url": "https://github.com/cloudhedge/atrs.git"
    },
    "publishConfig": {
      "@cloudhedge:registry": "https://npm.pkg.github.com"
    }
  }

  3. Publish:
  npm login --registry=https://npm.pkg.github.com
  npm publish

  4. Users configure (need GitHub token with read:packages):

  Create ~/.npmrc:
  //npm.pkg.github.com/:_authToken=ghp_xxxxxxxxxxxx
  @cloudhedge:registry=https://npm.pkg.github.com

  Then in Claude Desktop config:
  {
    "mcpServers": {
      "atrs": {
        "command": "npx",
        "args": ["-y", "@cloudhedge/atrs-mcp-server"]
      }
    }
  }

  ---
  Option 2: Simple Install Script

  Add an install script to your repo that users clone and run:

  install.sh:
  #!/bin/bash
  cd "$(dirname "$0")"
  npm install && npm run build
  echo "Add this to Claude Desktop config:"
  echo "{\"command\": \"node\", \"args\": [\"$(pwd)/dist/index.js\"]}"

  Users just:
  git clone git@github.com:cloudhedge/atrs.git
  cd atrs/atrs-mcp-server
  ./install.sh

  ---
  Comparison for Private Repos

  ┌────────────────────┬─────────────────────┬──────────────────────┐
  │ Method             │ Setup Effort        │ User Experience      │
  ├────────────────────┼─────────────────────┼──────────────────────┤
  │ GitHub Packages    │ Medium (one-time)   │ Clean npx install    │
  │ Install script     │ Low                 │ Manual clone + run   │
  │ Docker             │ Medium              │ Works everywhere     │
  └────────────────────┴─────────────────────┴──────────────────────┘

  Recommendation: For internal CloudHedge use, the install script is simplest. For wider distribution within the org, GitHub Packages is cleaner.
