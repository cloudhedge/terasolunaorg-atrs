     MCP Server Implementation Plan for ATRS

     Overview

     Build a custom MCP server that exposes ATRS flight reservation APIs to 
     Claude via user-friendly tools.

     ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
     │  Claude Code    │────▶│   MCP Server    │────▶│   ATRS APIs     │
     │  (MCP Client)   │◀────│  (Node.js/TS)   │◀────│  (localhost)    │
     └─────────────────┘     └─────────────────┘     └─────────────────┘

     Scope: Phase 1-2 Only (Initial)

     Decisions:
     - Use /flight endpoint (legacy REST API)
     - Accept English names (ASCII) - may need Katakana for production
     - Focus on project setup + API client verification first

     Phase 1: Project Setup

     Goal: Create MCP server skeleton with TypeScript

     Phase 2: API Client & Types

     Goal: Typed HTTP client matching ATRS API contracts

     Type Definitions (from exploration):

     // Request types
     interface FlightSearchQuery {
       flightType: 'RT' | 'OW'
       depAirportCd: string      // 3-letter code
       arrAirportCd: string
       depDate: string           // yyyy/MM/dd
       boardingClassCd: 'N' | 'S'
     }

     interface TicketReserveRequest {
       repFamilyName: string     // Full-width Katakana
       repGivenName: string
       repAge: number
       repGender: 'F' | 'M'
       repTel1: string           // 2-5 digits
       repTel2: string           // 1-4 digits
       repTel3: string           // 4 digits
       repMail: string
       flightType: 'RT' | 'OW'
       selectFlightResourceList: SelectFlight[]
       passengerResourceList: Passenger[]
     }

     // Response types
     interface FlightResource {
       flightName: string
       depAirportName: string
       arrAirportName: string
       depTime: string
       arrTime: string
       depDate: string
       boardingClassCd: 'N' | 'S'
       fareTypes: Record<string, FareTypeResource>
     }

     interface FareTypeResource {
       fareTypeName: string
       fare: string
       vacantNum: number
     }

     API Endpoints:
     | Endpoint                  | Method | Purpose                |
     |---------------------------|--------|------------------------|
     | /flight                   | GET    | Search flights         |
     | /ticket                   | POST   | Create reservation     |
     | /ticket/check?reserveNo=X | GET    | Verify reservation     |
     | /api/auth/status          | GET    | Check auth (200/404)   |
     | /api/member/available     | GET    | Check member (200/404) |

     ---
     Phase 4: MCP Tools

     Goal: 5 tools registered in MCP server

     Tool 1: search_flights

     Input: {
       from: string      // City name OR airport code
       to: string
       date: string      // ISO date (2025-01-15)
       seatClass?: 'standard' | 'premium'  // Default: standard
     }
     Output: Array<{
       flight: string
       departure: { airport: string, time: string }
       arrival: { airport: string, time: string }
       fares: Array<{ type: string, price: number, seats: number }>
     }>

     Tool 2: reserve_ticket

     Input: {
       flight: string        // Flight name (NH001)
       date: string          // ISO date
       fareType: string      // OW, RT, ED, etc.
       seatClass: string
       passengers: Array<{
         familyName: string  // Katakana
         givenName: string
         age: number
         gender: 'M' | 'F'
       }>
       contact: {
         name: string
         phone: string       // "090-1234-5678"
         email: string
       }
     }
     Output: {
       reservationNumber: string
       paymentDeadline: string
       totalFare: number
     }

     Tool 3: check_reservation

     Input: { reservationNumber: string }
     Output: { exists: boolean }

     Tool 4: list_airports

     Input: { region?: string }  // Optional: "Tokyo", "Osaka", etc.
     Output: Array<{ code: string, city: string, name: string }>

     Tool 5: list_fare_types

     Input: {}
     Output: Array<{
       code: string
       name: string
       discount: string
       requirements: string
     }>

     Checkpoint: All tools visible in MCP Inspector
